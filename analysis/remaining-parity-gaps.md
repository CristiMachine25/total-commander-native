# Remaining requirements for exact Total Commander parity

The requested exact application, theme, shortcuts, features and **all settings** remain unmet. Version 0.7.0 extends native functionality; it does not close the complete parity requirement.

1. **Original recovery and behavioral evidence.** Partial pseudocode exports, commands and help are not recovered complete source. Paired original/native scenarios across the original commands remain incomplete. Matrix rows overlap and are not independent missing-feature counts.
2. **Presentation and input.** AppKit controls, macOS chrome, dialogs, spacing, icon behavior and focus differ. Original menu order/labels are loaded, but unsupported entries remain disabled. Native toolbar customization and internal-command key remapping exist; Windows .bar compatibility, every modifier/context and full accessibility equivalence still require work.
3. **Panels.** Full, Brief, local Tree, Thumbnails and separate local trees exist. Branch/custom-column/comment modes, remote and change-allowed locked tabs, full per-tab settings, virtual tree parity, original thumbnail providers/cache, and complete Quick View behavior remain incomplete. Directory previews do not provide full recursive summaries; multimedia/plugins and separate-following Quick View are missing.
4. **Archives.** ZIP/ZIP64, supported password ZIP, 7z/TAR/compressed TAR/GZIP/BZIP2/XZ and RAR fixture reading are implemented and tested in bounded scopes. This does not establish every variant. Non-ZIP and password sessions are read-only; full ZIP64 writing, split archives, all encryption, external packers/plugins and original packing options are not established. ZIP mutation recompresses and may lose archive comments/extra metadata. Extraction refuses existing selected target roots instead of reproducing every merge dialog.
5. **Transfers and metadata.** Local collision policies, cancellation and provider transfers exist. Full ACL/xattr/resource-fork preservation, retries/resume, persistent queue journals and all original merge/confirmation behavior remain incomplete. Concurrent remote changes cannot be made transactional by FTP preflight checks: RNTO servers can overwrite between the check and rename. Recovery copies and retained backups mitigate failures but do not remove that race. Trash and permanent-delete parity require their own runtime evidence.
6. **Search, rename and synchronization.** Advanced search criteria, archive/plugin search, all rename tokens/presets/undo, binary diff/merge and complete original options are missing. Synchronization is copy-only for local trees and does not mirror deletions; incomplete scans and unsupported nodes are refused, and replacement originals are retained.
7. **Networking.** FTP requires MLSD. Resume, SFTP, ASCII/automatic transfer policy, all proxy/connection options and broad server interoperability remain unverified or absent. Local TLS rejection fixtures are not proof of successful trusted production FTPS.
8. **Plugins and integrations.** Native ARM64 cannot load Windows WCX/WFX/WLX/WDX DLLs. An equivalent native host and ported plugins are absent. Windows shell extensions, associations, platform utilities and full Lister encodings/multimedia are not reproduced.
9. **Configuration and ancillary tools.** There are 86 typed settings, not all original settings. Working Copy/Delete, Confirmation, Refresh, FTP and packer defaults were added; Custom Columns, View Modes/Auto Switch, plugin hosting and language packs still lack full implementations. Ignore List is display-only, not original recursive operation exclusion. Quick Search lacks the complete original dialog/options. Custom Columns, view-mode switching, complete Copy/Delete/Refresh/FTP/packer/plugin/language policies and full wincmd.ini compatibility remain incomplete. A native JSON editor/import/export and reported partial INI import now exist; original INI export/redirection, shortcut settings, plugin settings and credential import remain unsupported. Split/combine now exists with fixture-tested CRC handling, but MIME/BinHex encoding, printing, comments and other ancillary commands remain unassessed or absent. POSIX execution is not DOS semantics. See [configuration coverage](configuration-coverage.md).
10. **Performance.** Local benchmarks establish faster repeated size/date formatting, category navigation, selection/footer updates and directory metadata listing. They do not establish Windows speed parity. First-open settings latency is essentially unchanged; direct offscreen cell-factory timing did not improve. Local navigation still scans synchronously, first-time icon lookup may block, and scrolling/frame latency, cold caches, slow volumes and paired Windows scenarios need further measurement. See [performance evidence](configuration-performance.md), [pane measurements](pane-responsiveness.md), and [listing measurements](directory-listing-performance.md).
11. **Release/conformance.** Backend tests prove their fixtures only. The current mounted artifact, visible error paths, every supported settings effect and paired original/native scenarios need release-specific evidence. Consult [TEST-RESULTS.md](../TEST-RESULTS.md); Developer ID signing/notarization and non-Apple-Silicon support are not established.

[Coverage](native-coverage.md) describes implemented scopes. [The matrix](feature-matrix.csv) preserves original labels, IDs and evidence references; no row certifies exact parity.
