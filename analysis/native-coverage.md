# Native implementation coverage — 0.5.0

This is a partial native reconstruction of Total Commander 11.58.1, not an exact replica or recovered original project. It uses real macOS paths without Wine. Original resources establish documented intent, not runtime equivalence.

The 0.5 evidence matrix records 621 command declarations, 100 menu declarations and 136 keyboard records: **69 command, 41 menu and 62 shortcut records are marked partial (172 of 857); 685 remain unassessed.** These overlap and are not independent features. Unassessed does not prove absent. Numeric command routes and every original parameter are not implied by similar functionality. Original evidence columns and ordering are unchanged. Command 581 is partial because its native JSON editor is not full original INI-file compatibility.

## Validation boundary

Counts above describe independently passing fixture suites, not a claim that every latest change passed final packaging. The 0.5 work includes formatter/page caching, selective pane updates, cell reuse and prefetched metadata reuse. Measured scopes and non-improvements are retained in [configuration performance](configuration-performance.md), [pane responsiveness](pane-responsiveness.md), and [directory listing performance](directory-listing-performance.md). No paired Windows measurement was performed; ordinary local listing and first icon lookups can still block.

All 33 distinct test executions passed, including the separately completed final pane/provider checks; see the release ledger for execution details. [TEST-RESULTS.md](../TEST-RESULTS.md) is the authoritative release ledger for subsequent full-suite and mounted-artifact results. Earlier integrated and visible workflows verify their named previous-build paths only. No exact-parity row is claimed. [Current interface audit](current-parity.md), [settings coverage](configuration-coverage.md) and [remaining requirements](remaining-parity-gaps.md) describe current boundaries.
