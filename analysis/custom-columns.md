# Native custom columns

The design follows the extracted original English help, `dialog_usercolumns.htm` and `dlg_configcustomcolumns.htm`, from the locally inspected Total Commander distribution. Those describe up to 29 named sets, captions, width/alignment, expression text, field insertion, manual ordering, copying/deletion, name-width adjustment and horizontal scrolling. Empty names intentionally remain valid: the original hides unnamed sets from its menu while retaining numbered-command access.

Implemented native fields: `tc.name`, `ext`, `fullname`, `path`, `size` (configured formatting or bytes/kbytes/mbytes/gbytes), modified/creation/access date and time, and native attributes. Expressions combine literal text, multiple fields, positive one-based substring ranges, conditional quoted prefixes/suffixes, and the original documented date-format letters. Unknown fields, unsupported units and content plugins are rejected rather than displayed as fake values. Nonlocal creation/access metadata stays empty; modified metadata uses the provider listing. Fixed size units use binary divisors and two decimals. Standard Full columns remain independently configured.

Sets retain standard Name/Ext columns so file identity, marking, icons and context-menu behavior remain intact. Additional columns have stable identifiers and independent caption, width and alignment; numeric/date fields sort by their underlying values, with filename ties. Parsed expressions are cached per pane/set and invalidated on edits. Per-pane manual selection is exposed through the Show menu and is also used by named view modes.

Limits: no Windows WDX plugin host; no undocumented built-in media/version fields; widths use macOS points rather than Windows dialog units; native attribute labels do not emulate every Windows flag. Creation/access metadata uses local resource values when requested; this has not been benchmarked on slow remote-mounted filesystems. No Windows INI custom-column import is claimed.

Validation: 29 expression/model assertions cover built-ins, numerical ordering, interpolation, conditional missing values, substring bounds, date formatters, unsupported plugins, invalid widths, duplicate set IDs, and persistence round trips. 13 full-source AppKit pane assertions passed: column order/visibility, name-width policy and scrolling, rendered numeric values/alignment, numeric sorting, expression-cache invalidation, selection/mark retention, standard-view restoration, per-pane manual selection, and name/extension separation. Evidence: [0.8-custom-columns-tests.log](0.8-custom-columns-tests.log).
